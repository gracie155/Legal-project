## 单案文件说明

每个 `cases/<案号>.md` 保存北大法宝返回的**结构化裁判文书正文**，按原文分段：

> 审理经过 → 诉讼请求 → 辩方观点 → 本院查明 → 本院认为 → 争议焦点 → 裁判依据 → 裁判结果 → 权责关键词

- 案件元信息（法院、审结日期、案由、标的额、合议庭、代理人）列于文件头部
- 法宝库未收录的段落标注"（法宝库未收录该段）"
- 每案附北大法宝原文链接，引用前请打开核对
